Problem

Stars become a graveyard

You star “for later,” then never clean up. GitHub only allows unstarring one repo at a time.

Solution

Bulk clean in minutes

Filter the noise, multi-select, and unstar in one pass — without a cloud app or extra OAuth setup.

Install

Needs Node.js 18+ and the GitHub CLI.

gh auth login

2

Clone & run

npm install && npm start
